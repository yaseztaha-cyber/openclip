# Phase 5 Editorial Annotation Guidelines

## What Makes a Valuable Editorial Moment

A valuable editorial moment is a self-contained video segment that:

1. **Has a clear hook** — The opening captures attention within the first 3 seconds
2. **Preserves context** — The viewer understands what is being discussed without needing external information
3. **Delivers a payoff** — The segment reaches a meaningful conclusion, insight, or punchline
4. **Is complete** — It doesn't end mid-thought or leave the viewer hanging
5. **Is interesting** — It would make someone stop scrolling and watch

## How to Select Boundaries

### Start Boundary
- Begin at the start of a complete thought or sentence
- Include enough setup for the viewer to understand the context
- Do NOT start mid-sentence or mid-word
- Do NOT include excessive filler ("um", "uh", "so", "well")
- If the speaker takes a breath before an important point, start after the breath

### End Boundary
- End at a natural conclusion point (period, question mark, exclamation)
- Include the complete payoff or conclusion
- Do NOT cut off before the speaker finishes their thought
- Do NOT include trailing silence or filler
- If the speaker pauses briefly before continuing, end at the pause

### Duration
- Target: 15-60 seconds for short-form content
- Minimum: 10 seconds (shorter clips lack context)
- Maximum: 120 seconds (longer clips lose viewer attention)
- Duration should match the natural length of the idea being expressed

## Handling Special Cases

### Pauses
- Short pauses (< 2s) within a thought: include them
- Long pauses (> 3s) between thoughts: end the clip before the pause
- If a pause is part of the comedic timing, include it

### Incomplete Sentences
- If the speaker starts a sentence but doesn't finish it, this is usually NOT a good clip
- Exception: The incomplete sentence IS the point (e.g., "Wait, what?")
- Mark as "starts_mid_sentence" or "ends_mid_sentence" in warnings

### Overlapping Moments
- If two interesting moments overlap, annotate both separately
- Use the exact boundaries for each
- Note in the description that they overlap

### Continuous Explanations
- For long explanations, select the most impactful 15-60s segment
- Include the hook and the key insight
- Don't try to include the entire explanation

### Demonstrations
- Start just before the demonstration begins
- Include the "reveal" or result
- End after the demonstration completes

### Multiple Speakers
- Include enough context to understand who is speaking
- If a back-and-forth is interesting, include both sides
- Don't cut in the middle of a speaker's turn

## Editorial Categories

Select all that apply:

1. **Strong opening** — The first 3 seconds are immediately engaging
2. **Surprising information** — Contains unexpected facts or revelations
3. **Emotional reaction** — Shows genuine emotion (laughter, surprise, anger, sadness)
4. **Important explanation** — Explains something valuable or complex
5. **Funny moment** — Genuinely humorous
6. **Demonstration** — Shows how something works
7. **Story payoff** — Delivers on a narrative setup
8. **Strong opinion** — Expresses a clear, defensible viewpoint
9. **Transformation** — Shows before/after or change
10. **Useful information** — Provides actionable or educational value
11. **Other** — Doesn't fit other categories

## Importance Rating (1-5)

1. **Trivial** — Not worth clipping
2. **Minor** — Slightly interesting but not compelling
3. **Moderate** — Decent clip, could work in a compilation
4. **Strong** — Good standalone clip
5. **Exceptional** — Must-clip moment, highly shareable

## Confidence Rating (1-5)

1. **Very uncertain** — Not sure if this is actually interesting
2. **Somewhat uncertain** — Might be interesting to some audiences
3. **Moderate** — Reasonably confident this is interesting
4. **Confident** — Definitely interesting
5. **Very confident** — Unambiguously valuable

## Common Pitfalls

1. **Loudness ≠ Importance**: A loud moment is not necessarily an interesting one
2. **Completeness ≠ Quality**: A complete sentence is not necessarily a valuable clip
3. **Technical quality ≠ Editorial quality**: Good audio/video doesn't make boring content interesting
4. **Personal preference ≠ Universal appeal**: What you find interesting may not appeal to others
5. **Recency bias**: Don't overweight moments from the beginning of the video
